**DP-600 Exam Lab** è un simulatore interattivo per prepararsi all'esame Microsoft Fabric Analytics Engineer Associate (DP-600). 
Permette di esercitarsi con domande a scelta multipla, scegliere tra modalità studio ed esame, navigare tra i quesiti, controllare le risposte disponibili e rivedere gli errori. L'obiettivo è trasformare il materiale di studio in uno strumento pratico per allenarsi prima dell'esame.
Il sito è attualmente in fase di test, suggerimenti e modifiche a eventuali risposte sbagliate sono gradite.
