# Source Material

Questa repository contiene il materiale utilizzato come fonte per le domande del progetto **DP-600 Exam Lab**.

I contenuti sono stati analizzati e rielaborati con il supporto dell'intelligenza artificiale (AI) per ridurre le ridondanze, mantenere le domande più utili ai fini della preparazione all'esame ed escludere quelle relative ad argomenti non più previsti dal DP-600 o rimossi nei changelog più recenti dell'esame.

Il materiale originale viene mantenuto come riferimento per la creazione e l'aggiornamento delle domande del simulatore.
